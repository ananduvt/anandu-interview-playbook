# Machine Learning & AI Interview Questions

ML concepts, algorithms, deep learning, LLMs, and AI application design.

---

## Question Categories

### ML Fundamentals
- Supervised vs unsupervised learning
- Regression vs classification
- Overfitting, underfitting, bias-variance tradeoff
- Cross-validation, hyperparameter tuning
- Feature engineering, feature selection

### ML Algorithms
- Linear/logistic regression
- Decision trees, random forests
- SVM, KMeans clustering
- Gradient descent variants
- When to use each algorithm

### Deep Learning
- Neural networks, perceptrons
- Convolutional networks (CNN)
- Recurrent networks (RNN), LSTM, GRU
- Attention mechanisms
- Backpropagation, optimization algorithms

### Large Language Models (LLMs)
- Transformer architecture
- Pre-training vs fine-tuning
- BERT, GPT models
- Prompt engineering
- Hallucinations and mitigation

### Generative AI
- Retrieval-augmented generation (RAG)
- Vector embeddings, semantic search
- Vector databases
- LLM integration in applications

### Model Evaluation & Deployment
- Metrics: accuracy, precision, recall, F1, AUC
- Model validation, cross-validation
- A/B testing
- Model deployment, serving
- Monitoring model performance

### ML in Production
- Data pipeline, preprocessing
- Model versioning
- Handling data drift, model drift
- Cost optimization
- Fairness and bias mitigation
