# Interview Playbook 👋

A **living, shareable interview-prep playbook** — study notes across CS fundamentals, Java, Spring,
databases, distributed systems, DevOps, and more.

## Sections
- **Foundations** — SDLC, design principles, networking, RegEx, testing
- **Data Structures & Algorithms** — structures, algorithms, coding problems
- **System Design** — fundamentals, scalability & resilience
- **Java** — basics, OOP, patterns, collections, functional, concurrency, testing, advanced, versions
- **Spring & Web** — Spring Boot, web services, API styles, security, JPA/ORM
- **Databases** — ACID / BASE / CAP
- **Distributed & Cloud** — microservices, messaging (Kafka), caching, AWS
- **DevOps** — Git, build tools, CI/CD
- **Security & Vulnerabilities** — OWASP, secure practices
- **Interview Prep** — question bank, quick reference
- **Resources** — curated links · **[Backlog](backlog.md)** — topics to add

## How to use
- Browse by section in the left nav, or **search** (top bar).
- Each page is concise and interview-oriented. The [Quick Reference](interview-prep/quick-reference.md) is for last-minute revision.
