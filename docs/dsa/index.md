## Quick Interview Prep

**Must-know structures & algorithms:**
- **Arrays**: Binary search, sliding window, two-pointer, prefix sums
- **Trees**: BFS/DFS, inorder/preorder/postorder traversal, BST, balanced trees
- **Graphs**: BFS/DFS, shortest path (Dijkstra, Bellman-Ford), topological sort
- **Dynamic Programming**: Identify subproblems, memoization vs. tabulation
- **Complexity**: O(1), O(log n), O(n), O(n log n), O(n²) — know when each applies
