## Quick Interview Prep

**Before the interview:**
- Research company: business model, tech stack, recent news, culture
- Practice: coding problems (LeetCode), system design, behavioral stories
- Prepare questions to ask: team structure, tech challenges, growth opportunities

**During the interview:**

**Technical rounds:**
- **Coding**: Listen carefully, ask clarifying questions, think aloud, handle edge cases, optimize iteratively
- **System Design**: Scope (functional + non-functional requirements), estimate scale, propose high-level architecture, deep-dive, identify trade-offs
- **Behavioral**: Use STAR method, be specific (project names, metrics), show self-awareness, learn from failures

**Communication tips:**
- Clarify requirements before coding
- Explain your thinking; don't code in silence
- Ask for hints if stuck; demonstrate problem-solving approach
- Discuss time/space complexity trade-offs

**After the interview:**
- Send thank-you email (within 24 hours)
- Reference specific conversation points
- Express genuine interest in role
- Ask timeline for next steps if not mentioned
